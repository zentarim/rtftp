# Agent notes

Project agent skills live under [`.agents/skills`](.agents/skills). That directory is the root for skills in this repository.

Agree with the user before adding any new third-party dependency.

When creating or amending a Git commit, include a Co-authored-by trailer
with the current session model name and a fixed noreply address:

Co-authored-by: <model name> <noreply@cursor.com>

Example: Co-authored-by: Cursor Grok 4.5 <noreply@cursor.com>
